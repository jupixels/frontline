## Phase 2: terrain, maps, gameplay gaps, frontlines, skirmish AI, balance

Everything in GAME_PLAN §7 "Phase 2" and §8b "Phase 2", built on one branch.

### How to try it
- `npm run dev`, then Skirmish (or `/?quick=valley_pass&ai=hard`, `/?quick=coastal_strait&ai=normal,hard,normal&teams=0,0,1,1`, `/?quick=desert_oilfields&ai=easy,normal,hard`).
- Playtest helpers (skirmish only): `&speed=4` game speed, `&autoplay=normal` lets an AI play your side, `match.fastForward(300)` in the console, `&mute`.
