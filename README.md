# Frontline

A modern military real-time strategy game that runs in the browser. You fight with combined arms (infantry, armor, artillery, air and naval) over strategic points, in matches of 60–90 minutes. Play online 1v1, 2v2 or free-for-all over peer-to-peer WebRTC, or solo against the AI.

**Play:** https://jupixels.github.io/frontline/

## Development

```bash
npm install
npm run dev        # http://localhost:5173
npm test
npm run build
```
